Refund Sheet Generator

Upload an orders export. This tool sums the per-item amounts (values separated by |) and builds a clean refund worksheet with one row per order, ready to hand to whoever processes refunds.

1 Upload orders export

Click to choose a file or drag it here
.xls, .xlsx, or .csv — exported orders file

2 Build the refund sheet

Pulls Order Number, Customer → Name, Email, Primary Refund Details, Refund QR (column AC) and Other Banks (column AD) as-is. If a cell holds a QR, the QR link is pulled instead of the "View QR" text. Sums DP Total Amount per item → DP Total Amount, Allocation Amount → Order Total, and Outstanding Balance → Refund. Rows are sorted A–Z by email. When the same email appears on multiple orders, a TOTAL REFUND column shows the combined Refund for that email on its first row only (rows aren't merged). Adds a blank Note column for you to fill in.
